# 🏥 NHS A&E Breach Risk Analysis: 2010 to 2026

## 📋 Project Overview
This project analyses 15 years of real NHS England A&E performance data 
to identify breach risk patterns and understand why the NHS has consistently 
missed its 95% four hour target.

## 🔍 Key Findings
- NHS has missed the 95% target in 169 out of 184 months (92% of the time)
- 2022 was the worst year ever with only 57.6% of patients seen within 4 hours
- Winter months (December, January, February) consistently perform worst
- Performance has never recovered since COVID-19

## 🛠️ Tools Used
- Python (pandas, matplotlib, seaborn)
- SQL (SQLite)
- Power BI

## 📊 Data Source
NHS England Open Data — publicly available at england.nhs.uk
